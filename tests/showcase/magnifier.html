Screen Magnifier — Showcase

Standalone test harness for content/overlays/magnifier.js. Move the mouse over the mock call area below — a cursor-follow lens magnifies whatever is underneath it. The lens is built entirely from cloneNode(true) + CSS transform; it never reads video pixels, draws to a canvas, or calls getDisplayMedia (ARCHITECTURE.md §8). Each tile's live canvas.captureStream() video is mirrored into the lens by copying the <video> element's srcObject reference onto its clone.
