Smart Color Inversion Filter — Showcase

Standalone harness for content/filters/inversion.js. "Smart" invert flips page chrome but exempts video tiles / images from the double-flip so photos never look like film negatives. "Dim only" is the independent brightness knob (no inversion) — the actual fix for photophobia, since inverting an already-dark UI makes it brighter, not darker.
